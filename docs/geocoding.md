# 逆地理编码与地址模板

在「设置 → 逆地理编码」选择解析方式。有效修改会实时生效并自动保存；连续输入结束后约 350 毫秒应用，无需手动保存。无效或尚未填完的输入会保留为草稿并提示，不覆盖已生效的配置。

- **内置解析**：离线解析中国省、市、区，不需要 Key。
- **高德**：填写高德开放平台的 **Web 服务 API Key**。照片 GPS 为 WGS 84，后端先转换为 GCJ-02，再向高德请求详细地址（`extensions=all`）。请求包含坐标和 Key，不上传照片。

解析方式、Key 和字段组保存在本机 `settings.toml` 的 `geocoding` 中，重启后恢复。
这些选项不写入水印预设；切换照片、载入预设和恢复水印默认值不会覆盖本机配置。
导出开始时冻结配置，已开始的导出不受随后修改影响。

字段含义及可用路径见[高德地理／逆地理编码文档](https://lbs.amap.com/api/webservice/guide/api/georegeo#s6)。
设置页也提供该链接。

## 配置字段

每个输入框对应一个可插入的模板。省略共同的 `regeocode` 根节点，英文逗号表示按顺序拼接，点号分隔对象层级，数组项从 `0` 开始。

| 字段路径 | 插入模板 | 设置页的示例结果 |
| --- | --- | --- |
| `addressComponent.province,addressComponent.city,addressComponent.district,addressComponent.township` | `{省\|市\|区\|街道}` | 北京市海淀区燕园街道 |
| `formatted_address` | `{格式化地址}` | 北京市海淀区颐和园路5号北京大学 |
| `pois.0.name` | `{兴趣点0名称}` | 北京大学 |

三组字段默认已添加。每组字段以独立卡片显示，使用上方的「＋」添加，使用卡片右侧的删除按钮移除。修改自动生效后，到水印文字编辑器的「插入字段」菜单选择相同模板。多个字段直接连接，不增加分隔符；数组空值、缺失字段和 `null` 留空。四个直辖市的高德 `city` 可能为空，组合模板不会因此中断。

例如 `addressComponent.streetNumber.number` 会生成 `{门牌号}`，`roads.0.name` 会生成 `{道路0名称}`。叶子字符串和数字按值显示；直接选择非空对象或数组时显示其 JSON 内容。常用字段会转换为中文模板名，未收录的字段保留路径文字；生成重复模板时需调整字段组。

示例结果使用固定演示数据，不代表当前照片。实际水印使用每张照片自己的 GPS。内置方式只能填充省市区，高德独有字段会留空；没有 GPS 的照片也会留空。

## 请求与缓存

仅在模板引用地址字段且照片有 GPS 时请求高德。编辑器只读取后台已经完成的解析结果，不在界面渲染时访问网络。预览、完整合成和导出共用同一字段解析实现，富文本样式作用于整个地址模板。

同一 Key 和坐标的完整响应在进程内缓存一小时，修改字段组不必重新请求；不同 Key 或坐标分别缓存。失败结果短暂缓存 15 秒，避免重复消耗调用量。响应仅缓存在内存，不修改源照片 EXIF；Key 不进入预设或日志。网络超时、无效 Key 和配额错误会通过照片预览／导出错误显示。
