01 / 特色

从边框开始，
把细节交给你。

保留照片本身的表达，也给文字、色彩和拍摄信息一个合适的位置。

  1. 01

    灵活调整文字的位置（通过文字组），可以在照片的上面下面左面右面，以及另外一个文字组的上下左右！并且可以加边框。

  2. 02

    可以导出固定比例的照片，比如16:9，而且可以自由决定照片的放置位置（比如靠左）。

  3. 03

    Exif 可以编辑，应用到导出。

  4. 04

    自动根据照片GPS信息识别省市区（限中国区域（含港澳台））；支持通过地图选点添加 GPS，并写入导出图片。

  5. 05

    内置部分预设示例，也可以保存自己的边框水印预设。

  6. 06

    提取色卡（并支持若干种风格），并应用到渐变背景（可以添加颗粒噪声），或放置在任何地方。

  7. 07

    自定义logo，支持与文字灵活排版。

  8. 08

    如果原图含HDR Gain Map，导出的水印同时保留HDR Gain Map (此时图片大小会限制在 8192x8192，由于libultrahdr限制)。

  9. 09

    提供小工具，生成Motion Photo（实况照片）以及“黑白 + 彩色Gain Map”的照片。

  10. 10

    支持 MCP，可使用AI Agent操作软件，批量处理照片。

  11. 11

    不含任何恼人的Web技术 (Chromium 以及 Electron)，UI使用 gpui-kit 构建，照片处理使用vips。

03 / 照片小工具

也为照片，
多留一些可能。

除了边框水印，还提供 Gain Map 查看、黑白底图与彩色 Gain Map 生成，以及 Motion Photo 制作。

黑白底图 × 彩色 Gain Map

预览黑白底图与对应的彩色 Gain Map，导出包含两者的 JPEG。原图含 Ultra HDR Gain Map 时，水印导出也会保留它。

带 Gain Map 的输出尺寸上限为 8192 × 8192。

从视频，留下一张实况照片。

选择 MP4 视频中的片段和封面帧，生成 Motion Photo。需要另行安装包含 ffprobe 和 libx264 的 FFmpeg。

可自动检测 FFmpeg，也可手动指定可执行文件路径。

04 / MCP 接入

说出想法，
让 Agent 帮你调整。

通过本地 stdio MCP 连接 AI Agent。修改同步到当前窗口，你可以查看预览，也可以随时手动接着调整。

  1. 1

    打开 Lumen Frame

    安装 1.2.0 或更新版本，正常打开软件并导入照片。操作期间保持窗口打开。

  2. 2

    添加本地 MCP 服务

    在支持本地 stdio MCP 的客户端中，填写可执行文件路径，参数设为 --mcp-stdio，然后重新加载服务。

  3. 3

    让 Agent 读取工作区，再开始调整

    确认能看到 Lumen Frame 工具列表后，描述你要的样式。先看预览，满意后再导出。

Lumen Frame 本身无需模型 API Key，模型由 Agent 客户端提供。客户端需能在运行 Lumen Frame 的同一台电脑上启动程序。

macOS · mcpServers JSON
{
  "mcpServers": {
    "lumen-frame": {
      "command": "/Applications/Lumen Frame.app/Contents/MacOS/lumen-frame",
      "args": ["--mcp-stdio"]
    }
  }
}
Windows · mcpServers JSON
{
  "mcpServers": {
    "lumen-frame": {
      "command": "D:\\Apps\\Lumen Frame\\lumen-frame.exe",
      "args": ["--mcp-stdio"]
    }
  }
}

在客户端的 MCP 设置中添加本地服务，传输方式为 stdio。Windows 路径请替换为实际解压位置，保留配套 DLL；JSON 中反斜杠需写成 \\。

~/.codex/config.toml
[mcp_servers.lumen-frame]
command = "/Applications/Lumen Frame.app/Contents/MacOS/lumen-frame"
args = ["--mcp-stdio"]

在 ~/.codex/config.toml 中添加配置。示例为 macOS 路径，Windows 请替换为实际 exe 路径。

~/.dsh/cordis.patch.yml
- insert:
    - id: mcp-lumen-frame
      name: '@deepseek-ai/dsh-mcp-client'
      config:
        serverName: lumen_frame
        transport: stdio
        command: '/Applications/Lumen Frame.app/Contents/MacOS/lumen-frame'
        args: ['--mcp-stdio']

在 ~/.dsh/cordis.patch.yml 中添加配置。示例为 macOS 路径，Windows 请替换为实际 exe 路径。

macOS 安装包采用临时签名，首次打开若被系统拦截，可在 Finder 中右键应用并选择“打开”。Windows 请解压整个文件夹后运行 exe，勿单独复制程序。

Windows 发行包支持 AVIF，不接受 HEIC 和相机 RAW；macOS 使用完整 libvips，相关格式建议用实际照片验证。Linux 可从源码自行构建。
