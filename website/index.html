Lumen Frame

Lumen Frame 是一款添加边框水印的工具。
它还提供 Ultra HDR Gain Map 查看、黑白底图与彩色 Gain Map 生成，以及从视频制作 Motion Photo 的小工具。

02 / 功能特点

边框之外，还能控制什么

围绕照片排版、元数据和新照片格式设计的工作流。

01 / LAYOUT

文字和照片的位置，都能调整

文字组可分别放在照片上、下、左、右。固定比例画布也能调整照片的位置，例如在 16:9 画幅中靠左摆放，为右侧文字留出空间。

四侧文字组固定宽高比自由定位
02 / METADATA

拍摄信息可编辑，也能复用样式

EXIF 信息可编辑并写入导出文件。照片带 GPS 信息时，可自动识别省、市、区县。内置预设可直接使用，也能保存自己常用的边框和水印参数。

EXIF 编辑GPS 地名自定义预设
03 / ULTRA HDR

导出水印时保留 Gain Map

原图包含 Ultra HDR Gain Map 时，导出的水印照片会重建并保留 Gain Map。也可以单独查看 Gain Map，或制作“黑白底图 + 彩色 Gain Map”照片。

受 libultrahdr 限制，带 Gain Map 的输出尺寸上限为 8192 × 8192。

04 / MORE TOOLS

批量导出与 Motion Photo

照片队列支持一次处理多张照片；小工具还可从 MP4 视频生成 Motion Photo。后者需要单独安装 FFmpeg。

原生桌面技术栈 — UI 使用 gpui-kit，照片处理使用 libvips；应用本体不使用 Chromium 或 Electron。
